# LayToRest Unity Project

Unity version: `6000.4.10f1`

This project lives inside the `LayToRest/` subfolder of the repository.

## Collaborator Setup

1. Accept the Unity organization/project invitation and sign in to Unity Hub.
2. Clone the repository:

   ```powershell
   git clone https://github.com/lukketsvane/spelauget.iverfinne.no.git
   ```

3. In Unity Hub, choose **Add > Add project from disk** and select:

   ```text
   spelauget.iverfinne.no/LayToRest
   ```

Unity Hub does not automatically download or list a collaborator's project only because they were added to the Unity organization. They still need the project files from source control on their own machine.

## Source Control

GitHub is the primary download path for the project:

```text
https://github.com/lukketsvane/spelauget.iverfinne.no.git
```

Unity Version Control is also enabled for the Unity Cloud project `LayToRest` in the `iverfinne_unity` organization. After opening the project, use **Window > Unity Version Control** if your account has a Unity VCS seat and you want to work through Unity VCS.

Avoid checking in the same change to both systems without coordinating with the team. Pick one workflow for a task, then tell the team where the change was submitted.
